# Расшифровка медицинско-юридических документов

Сайт: загружаете фото/сканы страниц → получаете текст документа.

Распознавание — PaddleOCR (PP-OCRv5, русский/украинский/белорусский/английский), работает прямо в браузере через onnxruntime-web. Бесплатно, без ключей и сервера: фото никуда не отправляется.

## Структура

- `public/index.html`, `public/app.js` — страница: загрузка, сверка текста с фото, подсказки, копирование, скачивание .docx/.txt
- `public/ocr.js` — распознавание в браузере
- `public/models/` — модели PaddleOCR в ONNX (из huggingface.co/monkt/paddleocr-onnx)
- `public/models/words.txt` — 300 тыс. русских словоформ по убыванию частоты (hermitdave/FrequencyWords, OpenSubtitles 2018, CC BY-SA 4.0), отфильтрованных по списку danakt/russian-words
- `public/models/forms.txt` — ещё ~1,2 млн словоформ из danakt/russian-words, сжато (первый символ строки — длина общего начала с предыдущим словом + 48). Только для проверки, что слово существует
- `public/docx.js` — сборка .docx без библиотек
- `public/models/med.txt` — медицинские словоформы по частоте: из законов об охране здоровья, психиатрической помощи, судебно-экспертной деятельности, ОМС и лекарствах (Викитека) и медицинских статей русской Википедии (CC BY-SA), плюс медицинские сокращения. На сайте эти слова считаются частыми, поэтому термины («синусовый», «энцефалопатия») не «исправляются» на похожие обычные слова. Собирается `.tools/fetch-med.cjs` и `.tools/build-med.cjs`
- `public/models/ctx.txt` — какие слова и окончания стоят рядом в юридических и медицинских текстах (Гражданский и Гражданский процессуальный кодексы, медицинские законы, медицинские статьи Википедии; скрипты `.tools/fetch-codes.cjs`, `.tools/fetch-med.cjs`, `.tools/build-ctx.cjs`). Нужен, чтобы подсказки и окончания у краёв строк подбирались по контексту
- `public/vendor/` — onnxruntime-web 1.30.0
- `public/coi-serviceworker.js` — на GitHub Pages включает заголовки COOP/COEP через service worker, чтобы распознавание шло в несколько потоков (coi-serviceworker 0.1.7, MIT)
- `.github/workflows/pages.yml` — публикация `public/` на GitHub Pages при каждом изменении в `main`
- `api/send.js`, `vercel.json` — серверная отправка почты и заголовки, если сайт размещён на Vercel (необязательно)
- `dev-server.js` — локальный запуск

## Публикация

**GitHub Pages** (основной вариант): каждое изменение в ветке `main` публикуется автоматически (Settings → Pages → Source: GitHub Actions). Сервера нет, поэтому письма отправляются с почты пользователя (см. ниже).

**Vercel** (если нужна отправка писем с сервера):

```bash
vercel deploy --prod
```

## Локальный запуск

```bash
npm run dev
```

Откройте http://localhost:3000.

## Как повышается точность

- Модели разрешено выдавать только буквы, цифры и обычную пунктуацию — никаких «∀», «➀», «|».
- Наклонные строки выпрямляются перед распознаванием, яркость каждой строки растягивается (автоконтраст).
- Латинские буквы-двойники в русских словах заменяются на русские, регистр выравнивается («ДОгОВОР» → «ДОГОВОР»), лишние пробелы и пробелы у знаков препинания убираются, слипшиеся слова разделяются.
- Слова, которых нет в словаре, исправляются с учётом того, в каких буквах модель сомневалась. Исправленные подчёркнуты пунктиром, сомнительные — жёлтые, фамилии и отчества — фиолетовые (их стоит сверить с фото); нажатие показывает варианты.
- Медицинские термины и сокращения есть в отдельном словаре, поэтому их не заменяет похожее обычное слово.

## Сверка с фото

После расшифровки фото страницы показывается рядом с текстом. Строка и слово под курсором (или там, где стоит курсор ввода) подсвечиваются на фото, фото само прокручивается к ним; есть масштаб. Кнопка «Следующее слово на проверку» (Alt+↓ / Alt+↑) по очереди открывает сомнительные места с вариантами. На телефоне фото закреплено сверху.

## Отправка на email

Кнопка «Отправить на email» отправляет чистый текст и два .docx: «с пометками» и «чистовик».

**Без сервера (GitHub Pages):** на телефоне открывается меню «Поделиться» с обоими файлами (адрес копируется в буфер — вставьте его в письмо); на компьютере — Gmail или почтовая программа с готовыми адресатом, темой и началом текста, а файлы скачиваются для вложения.

**С сервером (Vercel):** письмо уходит сразу через Gmail чистый текст в теле письма и два .docx во вложении — «с пометками» (жёлтое выделение, догадки в скобках) и «чистовик» (без выделения, догадки целыми словами) (`api/send.js`, nodemailer). Нужны переменные окружения Vercel:

- `GMAIL_USER` — адрес Gmail отправителя
- `GMAIL_APP_PASSWORD` — пароль приложения Google (myaccount.google.com/apppasswords, нужна двухэтапная аутентификация)
- `SEND_PASSWORD` — пароль для отправки с сайта, чтобы посторонние не рассылали письма с вашей почты; сайт проверяет его сразу после ввода и запоминает в браузере. Можно дать ссылку `…/#send=ПАРОЛЬ` — пароль запомнится без ввода

Использованные адреса запоминаются в браузере и предлагаются в списке.

## Ограничения

- Печати, подписи и рукописный текст не распознаются; таблицы выводятся строками.
- PDF не принимается — загружайте страницы как фото или скриншоты.
- Слова, обрезанные краем фото, достраиваются по словарю и помечаются: `Арендода[тель?]`. Это догадка — сверяйте с оригиналом.
